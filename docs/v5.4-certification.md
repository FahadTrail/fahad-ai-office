## Observations, not changed

* **FINANCE's first draft** in the certification run included process narration. The existing V4.1 stripping handles the final version.
* **Command Center status** does not count decisions written as Office text. This is existing behaviour.
* **14 carrier runs stay `running`** after their coding session was cancelled or blocked. This is cosmetic, and the health snapshot counts these runs separately.
* **Grant hardening:** low severity, not applied, Fahad decides.
  * The legacy tables give `authenticated` TRUNCATE, REFERENCES and TRIGGER, and `anon` holds privileges on `office_owners`.
  * The owner-only RLS policies keep rows safe, and the Data API exposes none of these privileges.
  * SQL to tighten it:
    ```sql
    revoke all on public.office_owners from anon;
    revoke truncate, references, trigger on public.agents, public.approvals, public.events, public.files,
      public.handoffs, public.jobs, public.memory, public.office_owners, public.projects, public.results,
      public.runs, public.tasks from authenticated;
    ```
* **Leaked-password protection** is a Supabase dashboard switch. The Hub signs in by email code, so it is optional.
